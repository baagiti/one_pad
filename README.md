# Stick Trainer

Rhythm training app for a single practice pad. Generates practice sessions in
standard drum notation, plays a metronome, and — for Premium users — records
a take and scores timing accuracy against the notation.

See [docs/product_spec_v0.1.md](docs/product_spec_v0.1.md) and
[docs/technical_design_v0.1.md](docs/technical_design_v0.1.md) for the full
design.
